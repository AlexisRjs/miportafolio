## ✨ Características y Efectos Destacados

### 🪪 1. Credencial Interactiva con Física de Lanyard (`LanyardBadge`)
- Simulación de una credencial de conferencias colgante suspendida por un hilo de titanio.
- **Física de arrastre elástica:** Permite arrastrar la tarjeta con el cursor o en pantallas táctiles con balanceo gravitacional, inercia y retorno elástico amortiguado.

### 🖥️ 2. Terminal Interactiva Dev Sandbox (`alexis-sh`)
Emulador de terminal interactiva con historial mediante flechas de navegación ($\uparrow$ / $\downarrow$) y botones de acceso rápido:

| **🎮 Easter Eggs & Hacks** | `antigravity`, `matrix`, `hack`, `coffee`, `joke`, `quote`, `cat`, `roll`, `rickroll`, `git`, `dance`, `weather`, `calc [expr]`, `ping`, `whoami`, `sudo`, `secret`. |
| **⚙️ Sistema** | `theme` (conmutador Dark/Light), `clear` (limpiar pantalla). |

- Menú lateral responsivo optimizado para dispositivos móviles.

### ✨ 4. Border Glow Líquido Apple Pro
- Iluminación specular reactiva que se activa en el contorno exterior de las tarjetas y la terminal al pasar el cursor.

## 🔒 Auditoría de Seguridad & Privacidad

El repositorio y el servidor local aplican prácticas de seguridad defensiva:
- **Protección de Datos Personales:** Exclusión estricta de Curriculum Vitae (PDF), documentos de identidad y fotos privadas en [`.gitignore`](.gitignore) para evitar fugas accidentales en repositorios públicos.
- **Defensa contra Directory Traversal:** `dev-server.js` valida rutas canónicas y restringe peticiones fuera del directorio raíz.
- **Bloqueo Perimetral de Archivos Sensibles:** Bloqueo de peticiones dirigidas a `.git/`, variables de entorno (`.env*`), scripts de servidor (`dev-server.js`) y módulos.
- **Headers HTTP de Seguridad:** Encabezados `X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, `Referrer-Policy: strict-origin-when-cross-origin` y `X-XSS-Protection: 1; mode=block`.
- **Sanitización de Entradas:** Validación estricta mediante expresiones regulares en la calculadora de la terminal y sanitización de caracteres HTML contra inyecciones XSS.

## 🚀 Puesta en Marcha Local

### Prerrequisitos
- [Node.js](https://nodejs.org/) (versión 16 o superior).

### Instalación y Ejecución

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/AlexisRjs/miportafolio.git
   cd miportafolio
   ```

2. **Iniciar el servidor local con protecciones activas:**
   ```bash
   node dev-server.js
   ```

3. **Abrir en el navegador:**
   Ingresa a [http://localhost:3000](http://localhost:3000).
